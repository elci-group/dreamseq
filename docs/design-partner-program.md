# Design Partner Program

## Ideal partner

An engineering-platform team with 20–200 engineers, active use of two or more
AI coding harnesses, and an existing interest in measuring agent reliability or
developer workflow friction.

## Four-week pilot

1. **Week 0 — discovery:** choose harnesses, repositories, data boundaries,
   owner, and baseline metrics.
2. **Week 1 — local baseline:** run Dreamseq offline and review ingestion
   quality and privacy boundaries.
3. **Weeks 2–3 — intervention:** select two high-confidence directives and
   apply them to the team workflow.
4. **Week 4 — review:** compare baseline and post-intervention metrics and
   decide whether to expand, pause, or stop.

## Partner ask

- one technical owner and one engineering manager;
- anonymized or locally processed logs;
- two 45-minute feedback sessions;
- permission to use aggregated, non-identifying outcomes in a case study;
- no production secrets or regulated data in the pilot source paths.

## Outreach message

> We are testing a privacy-conscious way to measure where AI coding agents
> create rework: model failures, missing tools, context loss, and harness
> friction. A four-week pilot runs locally first, produces evidence-backed
> interventions, and does not require sending raw logs to a service. Would your
> platform team be willing to review a short baseline workflow?

External partner recruitment and commitments require maintainer approval; this
repository does not claim that design partners have been secured.
