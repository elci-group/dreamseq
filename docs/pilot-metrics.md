# Pilot Metrics

Track the following before and after each intervention. Metrics are decision
signals, not individual employee scores.

| Metric | Definition | Target signal |
|---|---|---|
| Agent rework rate | Sessions requiring repeated correction for the same issue | Down |
| Human steering frequency | Steering events per analyzed session | Down |
| Context-loss recurrence | Repeated context-loss findings per week | Down |
| Missing-tool recurrence | Repeated missing-tool findings per week | Down |
| Time-to-resolution | Median time from failure to accepted outcome | Down |
| Adoption | Sessions using the selected intervention | Up |
| Data completeness | Accepted entries / files seen | Up |
| Privacy exceptions | Approved source or redaction exceptions | Zero unexplained |

Use cohort-level aggregation and suppress small groups. Do not use Dreamseq
outputs for individual performance evaluation without a separate governance
process.
